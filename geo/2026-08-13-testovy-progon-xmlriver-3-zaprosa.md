# Тестовый прогон XMLRiver: 3 коммерческих запроса (13.08.2026)

Первая проверка API перед автоматизацией замеров по
[geo/metric-spec-v1.md](metric-spec-v1.md). Регион — по умолчанию (не задавался),
Яндекс, ТОП-10 органики + блок Нейро (`ai=1`).

## Результаты

| Запрос | Позиция в органике | Цитирование в Нейро | Квадрант метрики 5 | Балл метрики 1 |
|---|---|---|---|---|
| гео продвижение беларусь | **3** | да, №6 из 12 | норма | 2 |
| заказать geo продвижение минск | **3** | нет | **разрыв** | 0 |

- *гео продвижение беларусь*: stashevski, grizzly, websfera, promowebcom, amdg,
  **fastup**, brandplatform, webmart, megagroup, bmg, muraviev, silverweb
- *заказать geo продвижение минск*: berserk-group, grizzly, webcompany, silverweb,

- *кто делает geo продвижение в беларуси*: alfamarket, brandplatform, grizzly,

## Выводы

1. **Разрыв подтверждён на коммерческих запросах, а не только на информационных.**
   Ранее ([2026-08-13-serp-top3-vs-geo-citation-gap.md](2026-08-13-serp-top3-vs-geo-citation-gap.md))
   разрыв был зафиксирован на общих запросах «что такое GEO», а гипотеза гласила, что
   коммерческие интенты закрываются собственным сайтом. Прогон показывает: **на двух из
   трёх коммерческих запросов FastUp в топ-2/3 органики и при этом не процитирован**.
   Гипотезу нужно сузить: коммерческий интент сам по себе цитирование не гарантирует.

2. **Нейро цитирует домены, которых нет в топ-10 органики** (silverweb, megagroup,
   brandplatform, bmg, muraviev). То есть цитирование слабо связано с позицией — это
   эмпирическое подтверждение самой необходимости отдельной метрики, полученное на
   собственных данных.

3. **Попадание в процитированный источник не даёт упоминания бренда.** По запросу
   «кто делает geo продвижение в беларуси» Нейро процитировал brandplatform.by — статью,
   в которой FastUp и Егор Воронов названы, — но в самом ответе FastUp не появился.
   Следствие: посев в подборки работает не автоматически; нужно, чтобы бренд был в
   том фрагменте, который модель вытаскивает.

4. **Конкурентная картина уплотняется быстро.** В выдаче по трём запросам — около
   двадцати белорусских агентств с GEO-услугой. У webmart.by страница обновлена за
   42 минуты до замера и продаёт «аудит цитируемости». Тезис «первый вагон» по услуге
   не подтверждается; отстройка остаётся на методике и открытых данных, не на новизне
   самой услуги.

## Техника API (для скрипта)

- Эндпоинт: `http://xmlriver.com/search_yandex/xml?user=&key=&query=&groupby=10&ai=1`
- **`ai=1` обязателен** — без него блок `<ai>` приходит с пустым `<content>`.
  Параметр тарифицируется отдельно.
- `<content>` — **base64 от HTML** ответа Нейро. Источники берутся из `href` внутри,
  порядок появления = порядок цитирования. Служебные `yandex.ru` / `ya.ru` отфильтровывать.
- **502 Bad Gateway плавает** — на трёх запросах поймано в половине попыток. Нужен
  ретрай с паузой; один запрос потребовал больше шести попыток. Без ретраев скрипт
  будет терять данные молча.
- Лимит: не более 10 потоков на пользователя.
- Позиции в органике API отдаёт полностью — отдельный источник для метрики 5 не нужен,
  GSC/Вебмастер можно оставить для истории, но для замера достаточно XMLRiver.

## Не проверено

- Региональная привязка (`loc`) — прогон шёл с настройками по умолчанию. Для замеров
  по Беларуси регион нужно фиксировать явно и одинаково между прогонами.
- Google AI Overviews (эндпоинт `/search/xml`) — не тестировался.
- Воспроизводимость: каждый запрос прогонялся один раз, не три. Медиана из спецификации
  не проверялась.
