# Технический разбор формата «пост» на Хабре: что из него получает нейросеть

Разобран живой пост Егора: https://habr.com/ru/posts/1078784/ (парсинг HTML 2026-09-05).
Контекст и позиция — `expert/opinions/2026-09-05-habr-posty-indeksiruyutsya-i-popadayut-v-alisu.md`.

## Что есть в HTML (всё server-side, без JS)

Блок автора отдаётся в исходнике и содержит полную связку сущности:

- `Егор Воронов` — имя
- `@Asmodey_dev` — ник, ссылка на профиль
- `основатель FastUp.by` — отдельным полем `speciality` (Хабр маркирует это как
  должность, а не как произвольный текст в теле)
- `<a href="https://fastup.by" rel="noopener" target="_blank">Сайт</a>` — **без nofollow**
  (на странице 7 nofollow, ни один не на этой ссылке)

Вывод: цепочка человек → должность → компания → домен собрана целиком и доступна
краулеру. Подпись доработки не требует.

## Чего в формате «пост» нет (и не будет — это устройство формата)

1. **Нет заголовка.** `<title>` и `og:title` = «Пост @Asmodey_dev — Веб-разработка —
   05.09 10:13». Тема поста в заголовок не попадает вообще. `<h1>` на странице
   отсутствует. Это не «плохой заголовок», а его отсутствие.
2. **Нет JSON-LD.** Ни одного блока `application/ld+json`. У статей Хабра разметка
   есть, у постов нет — связь автор↔компания держится только на тексте.
3. **`canonical` корректный**, `meta robots` отсутствует (то есть индексация открыта).

## Управляемый сигнал: первое предложение

Проверено: `meta description`, `og:description`, `twitter:description` и
`aiturec:description` (яндексовое) заполняются **первым предложением поста дословно**.

Поскольку заголовка у формата нет, **первая фраза поста — единственный
заголовочный сигнал, которым автор управляет**. Правило для всех будущих постов:
первое предложение называет тему прямым текстом, без разгона и без лирического
вступления. Всё остальное в посте свободно.

## Практический вывод по каналу

Формат «пост» пригоден для entity-задачи (упоминание + связка + dofollow-ссылка на
авторитетном домене) и непригоден для тематического ранжирования (нет заголовка,
нет разметки). Это ровно тот размен, который нас устраивает: Хабр у нас — источник
упоминаний, не трафика.
