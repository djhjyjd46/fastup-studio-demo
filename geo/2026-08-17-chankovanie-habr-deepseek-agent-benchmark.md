# Прогон «Чанкование» — Habr, «DeepSeek Pro vs Flash, 7 задач агента» (`content/ai-agent-benchmark.md`)

Площадка: Habr. Правила — `content/platform-rules.md` (раздел Habr есть, полный). Единица
поиска — **тема**, не живой покупательский запрос (см. метод, раздел про Хабр/vc.ru):
трафик у Habr идёт из ленты, но статьи индексируются и цитируются Google/AI Overview за

видно в поиске Habr».

## Замер «до» (2026-08-17, Yandex Cloud Search v2 region=149 + Google XMLRiver country=by)

8 подзапросов из декомпозиции трёх разговорных промптов, полный прогон
`scripts/fetch_serp_competitors_per_intent.py`, LM Studio (`text-embedding-qwen3-embedding-8b`)
поднята и использована для векторизации H2. Отчёты по каждому подзапросу лежат рядом:
`geo/2026-08-17-serp-competitors-<slug>.md`, сводка — `geo/2026-08-17-serp-competitors-deepseek-agent-benchmark-SUMMARY.md`.

Три исходных разговорных промпта и их декомпозиция:

1. **«Какую модель DeepSeek выбрать для AI-агента — Pro или Flash?»**
   → `DeepSeek Pro vs Flash сравнение`, `DeepSeek Pro ошибки в задачах агента`,
   `DeepSeek Flash thinking reasoning effort`, `надёжность моделей в AI-агентах бенчмарк`
2. **«Дешёвая модель с thinking против дорогой без — что надёжнее для агента?»**
   → `дешёвая модель с thinking против дорогой модели без размышлений надёжность`,
   `стоимость токенов DeepSeek Pro Flash цена сравнение`
3. **«Как выбрать модель для AI-агента: дешевле или точнее?»**
   → `какую модель выбрать для агента дешевле или точнее`, `сравнение LLM для AI-агентов`

## Чего не хватает в черновике — конкретно

1. **Нет отдельного методологического раздела** («как мы измеряли», критерии успеха/провала
   задачи) — у двух конкурентов (`habr.com/886198`, `openlegion.ai`) это отдельный крупный
   блок. У нас критерий "✅/❌/⚠️" в таблице неявный — не объяснено, что считается провалом
   в задаче 4 (другая интерпретация — не error).
2. **Нет объяснения механики thinking-режима для читателя, не работавшего с DeepSeek API** —
   абзац "что такое reasoning-токены и почему они есть у не-thinking моделей тоже" закрыл
   бы подзапрос `DeepSeek Flash thinking reasoning effort` (сейчас топ-3 держат
   `api-docs.deepseek.com`, `huggingface.co`, `chat-deep.ai`, все — документация/гайды).
3. **Слабое явное противопоставление с публичными бенчмарками** — у нас есть фраза
   "не абстрактных синтетических тестах", но конкурент `vc.ru/ai_reviews/2738346` строит
   на этом целую статью ("бенчмарки врут"). Стоит усилить формулировку тезиса в начале, а
   не только в примечании.
4. **Нет матрицы "задача → какая модель лучше"** обобщённо за пределами наших 7 задач — не
   обязательно добавлять (у нас другой жанр, честный n=7), но явно сказать в тексте, что
   это не замена общего гайда по выбору модели, снимет ожидание читателя, который искал
   `какую модель выбрать для агента дешевле или точнее` и наткнулся на узкий кейс.

## Задача-продолжение (Flash Hi по умолчанию, полная статистика)

Проверено: `content/ideas.md` уже фиксирует это отдельной строкой бэклога как
«DeepSeek Pro vs Flash vs Flash Hi на агенте OpenClaw — 7 задач, полная статистика» со
статусом **`not-yet (ждёт накопления статистики)`**, ссылка на `notes/raw/2026-07-25-deepseek-benchmark-practice-change.md`.
Сам raw-файл дословно фиксирует то же самое от Егора: «семь задач — это ещё не показатель...
полную статистику можно будет собрать только через несколько месяцев... это уже будет
отдельная статья».

**Рекомендация: не обогащать текущий черновик, оставить как отдельное продолжение.**
Причины, помимо уже зафиксированного решения Егора:
- Текущий черновик — самодостаточный n=7 срез с чистым выводом (дорогая ≠ надёжнее); статья
  о накопленной статистике за месяцы — другой жанр (лонгитюдный трекинг), смешивание урежет
  оба текста и потребует переписывать таблицу результатов.
- Раздельные статьи дают Habr две публикации по смежным подзапросам вместо одной — по методу
  «чанкование» поле уже фрагментировано на 8 узлов ни одним доменом не закрытых целиком,
  вторая статья через 2-4 месяца может занять ещё один узел (`nadezhnost-modeley-ai-agent-benchmark`)
  отдельно, с более сильной статистикой, вместо того чтобы разбавлять первую.

## Вопросы Егору

1. Черновик пока без итогового заголовка — при выборе заголовка учесть, что подзапрос
   `DeepSeek Pro vs Flash сравнение` уже держит `checkroi.ru`/`aitunnel.ru` с явными
   "vs"-заголовками; наш заголовок должен явно сигналить угол "агент, реальные задачи",
   не конкурировать с ними за тот же самый заголовочный паттерн.
2. Нужен ли явный абзац "чем это не является" (не замена общего гайда по выбору модели,
   не публичный бенчмарк) — снимает разрыв ожиданий у части читателей из поиска, но
   расширяет объём статьи. Решение — на content-writer/Егора при ревью.
