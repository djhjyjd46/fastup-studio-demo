# GEO — стратегия и мониторинг

Заметки о том, как AI-системы (ChatGPT, Perplexity, Google AI Overviews, Claude и др.)
сейчас отвечают на вопросы про FastUp, куда ещё нужно «просочиться» описанием компании
(факты — `../positioning/facts.md`, смысл — `../positioning/messaging.md`), и что мешает
согласованному ответу.

Формат заметки: дата проверки → какой запрос задавали → что ответила система → расхождения
с нашими фактами → что сделать.

## Что где лежит

👉 **[Полный автоматический реестр всех 200+ отчётов и замеров GEO → `INDEX.md`](INDEX.md)**

**Методика и метрики:**
- `metric-spec-v1.md`, `metric-formulas.md` — NVI / CBK / PKS: **настоящий** замер видимости
  в ИИ, через прогоны реальных запросов к реальным системам.
- `GEO-RAG-COMMERCIAL-PIPELINE-FRAMEWORK.md` — регламент проектирования коммерческой страницы
  (интенты → пробелы → структура → текст → ревью → выкатка). Ревизия 2026-08-15 убрала из него
  недоказуемые заявления, раздел «What this framework measures, and what it cannot» читать
  обязательно.
- `GEO-AUDIT-PIPELINE.md` — порядок аудита.

**Карты интентов:**
- `MASTER-INTENT-MAP-2026.md` / `.json` — распределение по страницам. ⚠️ Проценты «доли
  спроса» в нём не посчитаны из частотностей (суммы не сходятся в 100%) — читать как
  экспертный приоритет, пока не пересчитаны.
- `../content/research/geo-page/INTENT-MAP.md` — реальные частотности Wordstat с разбивкой
  Россия / Беларусь. Ключевой факт оттуда: спрос на GEO в Беларуси близок к нулю
  (см. также `2026-08-13-wordstat-intenty-geo-metriki.md`).

**Замеры покрытия интентов** (локальный косинус — редакторский инструмент, **не** прогноз
видимости в ИИ и не рейтинг конкурентов):
- `2026-08-15-INTENT-COVERAGE-BENCHMARK.md` — 5 разделов, FastUp против 12 студий.
- `2026-08-15-GRAND-BENCHMARK-BEFORE-VS-AFTER.md` — 25 вопросов клиента, до/после
  переработки, с отдельным списком просадок.

Оба генерируются скриптами (`scripts/compute_all_sites_temperature_benchmark.py`,
`scripts/run_grand_baseline_benchmark_2026_08_15.py`) через общий `scripts/geo_embed.py`.
Второй скрипт удалён 2026-09-05 как одноразовый (замер 15.08 разовый, его результат —
в самом отчёте); первый и `geo_embed.py` живы, повторный прогон делается ими.
**Правило: цифры в эти отчёты вписываются только прогоном.** Ручная правка чисел в
сгенерированном отчёте — это то, из-за чего удалён
`2026-08-15-ALL-SITES-TEMPERATURE-LEADERBOARD.md` (история в git).
