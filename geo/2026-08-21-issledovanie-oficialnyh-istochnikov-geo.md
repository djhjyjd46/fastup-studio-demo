# Проверка официальных источников: llms.txt, микроразметка, чанкование под RAG

Исследование по запросу Егора 2026-08-21 — проверить, действительно ли принудительная
структура контента (llms.txt, жёсткие триплеты под RAG-извлечение) нужна для попадания
в AI-цитирование, или это индустриальный миф.

## Главный факт: официальный гайд Google

**15 мая 2026** Google опубликовала первый официальный документ «Optimizing your website
for generative AI features on Google Search». **15 июня 2026** обновила его пунктом про
llms.txt: файл не влияет ни на ранжирование, ни на AI Overviews, ни на AI Mode, потому что
Google Search его не использует вообще. Механика: RAG берёт страницы из уже существующего
поискового индекса, страница, которая не ранжируется обычным SEO, не попадёт в цитирование
никаким способом. Явно перечислено, что НЕ требуется: специальный AI-schema, llms.txt,
принудительное чанкование контента, AI-специфичные переписывания текста.

Источники: [SolCrys, пересказ гайда Google](https://solcrys.com/google-endorses-aeo-fundamentals/),
[Google Says llms.txt Does Nothing for SEO Rankings](https://www.digitalapplied.com/blog/google-llms-txt-no-seo-value-lighthouse-audit-2026).

| Домен | Файл есть? |

| google.com | Нет (404) |

| anthropic.com | Нет (404) |

Файл прижился только у devtools/API-платформ (аудитория — разработчики, которые физически
читают такие файлы), не у потребительских гигантов. Подтверждает позицию Google.

## Яндекс — та же позиция

Официально: генеративные ответы Яндекс.Нейро строятся на основе обычной поисковой выдачи,
отдельной оптимизации «под Нейро» не требуется. Страница, не ранжирующаяся по теме, не
попадёт в источники никакими трюками. Отдельной документации про llms.txt у Яндекса нет —
тема для них не существует.

## Микроразметка (schema.org) — работает на Этап 1, не на цитируемость

Три подтверждённые функции: (1) Rich Results — визуальные элементы выдачи, (2) Knowledge
Graph — Organization/Person/Brand-разметка подтверждает сущность компании, (3) отдельное
исследование ([SEroundtable](https://www.seroundtable.com/study-schema-citations-study-41311.html))
показало, что добавление schema само по себе **не увеличивает** цитируемость в AI-ответах.
Вывод: микроразметка — машиночитаемая фиксация фактов о компании, инструмент «Представления»
(см. [[../expert/opinions/2026-08-21-tri-etapa-geo-i-differentsiatsiya-po-segmentam]]), не
инструмент попадания в топ цитирования.

## Личный эксперимент Егора — подтверждает вывод практикой

Статья без дословного совпадения с запросом (совпадение по интенту, не по заголовку) была
процитирована Яндекс.Нейро **7 раз в одной выдаче** на один вопрос. Текст ответа был
**полностью пересобран нейросетью** — ни один фрагмент не совпадал дословно со страницей.

Дополнительное наблюдение (сравнение старого и нового поведения): раньше в «быстрых
ответах» Яндекса при наведении на источник подсвечивался конкретный фрагмент страницы,
откуда буквально взят текст (экстрактивный режим — выдача цитировала дословно, пример:
запросы «как варить пельмени», «как жарить яичницу»). Сейчас источник просто указывается,
без совпадения текста — выдача генеративная, пересказывает своими словами. Это объясняет,
почему требование «жёстких фактоидных триплетов под RAG-извлечение» устарело: раньше оно
могло иметь смысл (экстракция), сейчас — нет (генерация).

**Правка внесена в `content/PIPELINE.md`, шаг 4 — geo-callout остаётся как элемент
читаемости для человека, требование триплетов под RAG убрано.**

## Дополнение 2026-08-23: ещё находки с западного рынка (по запросу Егора)

- **Объём текста не влияет на цитируемость** (Ahrefs, 174 048 страниц): корреляция между
  количеством слов и позицией цитирования почти нулевая (Spearman = 0.04). 53.4%
  цитируемых страниц — меньше 1000 слов, страницы 2000+ слов — только 16% цитат.
  Разрушает миф «чем длиннее, тем авторитетнее».
- **Бренд-упоминания в 3 раза сильнее коррелируют с ИИ-видимостью, чем обратные ссылки**
  (0.664 vs 0.218, Ahrefs, 75 000 брендов, август 2025).
- **57% цитат по брендовым запросам уходят на сторонний контент** (обзоры, форумы,
  соцсети, кейсы), не на сайт самого бренда — подтверждает необходимость Этапа 3
  (Авторитетность через внешние площадки), собственный сайт не покрывает этот слой.
- **Оригинальные исследования цитируются в 3-10 раз чаще обычных блог-постов**,
  подтверждено 4 независимыми датасетами 2026 года — прямое обоснование стратегии
  со Статьёй 2 (FastUp GAS) как исследовательского материала, не рядовой статьи.
- **Листиклы — 63% всех цитирований** (анализ ~400 млн цитат ChatGPT/Copilot/Gemini/
  Google AI Mode/AI Overview/Perplexity), из них 71-86% — нумерованные топ-N списки.
  По отраслям паттерн разный: B2B tech — листиклы 61%, локальные услуги — главные
  страницы 55%, высшее образование — страницы программ 53%.
