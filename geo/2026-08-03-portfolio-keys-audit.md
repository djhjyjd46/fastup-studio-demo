# Аудит портфолио «Наши работы» (CPT `keys`) — 2026-08-03

Продолжение [2026-08-03-site-content-audit.md](2026-08-03-site-content-audit.md). Егор
поднял отдельно: страницы отдельных работ в архиве `/nashi-raboty/` не находятся в поиске
(не топ-20, не топ-100), и попросил проревьюить содержимое — заодно объяснил замысел:
эти страницы должны сами попадать в индекс и быть источником для нейросетей, как и статьи
блога, не только листаться в архиве.

## Находки

Все 17 опубликованных записей (`wp-json/wp/v2/keys`) на момент проверки не имели реального
текста на самой странице работы (не в архиве-списке, а на индивидуальной странице):
- **2 записи** — буквальный `Lorem ipsum dolor sit amet...` (id 1587 «Семья-Агро», id 1559
  «SelAuto»).
- **8 записей** — заголовок/excerpt скопирован как «тело» страницы, местами продублирован
  4-5 раз подряд (id 2243, 2168, 2146, 2131, 1892, 1714, 1687, 1686).
- **7 записей** — тело страницы полностью пустое (id 1694, 1693, 1692, 1691, 1690, 1689, 1688).

Плюс проблема с данными: поле «Клиент» у нескольких записей (2131, 2146, 1892) содержало
не имя клиента, а копию excerpt.

**Техническая деталь, из-за которой первая попытка правки не сработала:** индивидуальный
шаблон (`single-keys.php`) рендерит НЕ стандартный `post_content`, а отдельное ACF-поле
`description` (`get_field('description', $post_id)`) — это поле не входит ни в один
зарегистрированный ACF field group с `show_in_rest` (в отличие от FAQ, где хотя бы была
JSON-группа с неверной настройкой — здесь поля вообще нет в зарегистрированных группах,
доступ только через прямой `get_field()`/postmeta). Обновление через REST API `content`
не даёт эффекта на живой странице. Рабочий путь — WP-CLI: `wp eval-file` со скриптом,
вызывающим `update_post_meta($id, 'description', $text)`.

## Что сделано

Собраны короткие (2-4 предложения) честные описания по единому шаблону: тип сайта + ниша
клиента + технологии + что реально делали — без выдуманных результатов/цифр, которых по
этим 17 проектам не существует. Основа: уже введённые ACF-факты (`тип_сайта`,
`technologies`, `sale_link`) плюс дословная диктовка Егора с реальными деталями по 6
записям (vkusno-chisto → Tilda не WordPress; id 2243/1892 — реальные оплаченные клиенты,
временно на поддомене fastup.by; id 2168 — вероятно домен `.ru` по ошибке/экономии; «Кейс
Тур» — встроенный React-модуль подбора туров с картой; Royal House — mobile-first, один из
первых сайтов на чистом Tailwind, модуль бронирования; «Артблок» — объединение нескольких
региональных сайтов в один с редиректами; «Прайдмоторс» — собран за 2 дня из готовых
блоков; SelAuto — один из первых сайтов на Tailwind, резиновая вёрстка на сетке 1600px).
Дословная запись — `notes/raw/2026-08-03-keys-portfolio-details.md`.

Черновик прогнан через `content-reviewer` дважды (полный первый проход + точечный повтор
после добавления новой фактуры). Найдено и убрано: техническая догадка про калькуляторы
(не относится к этому файлу, отдельная правка того же дня), overstate про «переход к
бронированию» в кейсе «Кейс Тур» (Егор сам сказал «не знаю, наверное» — убрано, оставлена
только подтверждённая часть про карту направлений).

**Сознательно не выведено в публичный текст** (риски, зафиксированы в
`notes/raw/2026-08-03-keys-portfolio-details.md`):
- Прайдмоторс оплатил без договора, по чеку — не для публичного текста.
- Фудгарден = клиент из анонимизированного `cases/cloaking-removal-seo-case.md` — связь
  не выводится, деанонимизация без отдельного согласия клиента не делается.

Опубликовано на все 17 живых страниц через WP-CLI (`update_post_meta`). Проверено на живой
странице (`selauto`): Lorem ipsum убран, новый текст на месте.

## Индексация

Проверено отдельно по запросу Егора («там новый noindex стоит»): на момент проверки
2026-08-03 все 17 страниц отдают `<meta name="robots" content="follow, index...">` — не
noindex. Кастомный сайтмап темы (`https://fastup.by/sitemap.xml`, генерируется
`functions.php`, не Rank Math) уже включает все 17 URL `/keys/*`. Если Егор видел noindex
в другом месте (Google Search Console с устаревшим кэшем, или конкретная галочка в
Rank Math на одной странице) — нужно уточнить точное место, текущее живое состояние сайта
проблемы не показывает.

## На будущее — кандидаты в полноценные кейсы

Из дословной диктовки Егора выделяются как минимум 3 записи с реальной технической
фактурой сверх шаблонного описания, достойные отдельного кейса в `cases/`, если понадобится
больше материала для GEO: «Кейс Тур» (React-модуль с картой), Royal House (аналогичный
модуль + один из первых Tailwind-сайтов, mobile-first) и «Артблок»/SelAuto (техническая
история объединения сайтов и ранний опыт с Tailwind-сетками). Прайдмоторс — тоже кандидат
как пример скорости (2 дня), но требует переформулировки истории оплаты без упоминания
отсутствия договора.
