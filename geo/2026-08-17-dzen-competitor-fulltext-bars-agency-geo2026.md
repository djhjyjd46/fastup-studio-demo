## Полный текст (as fetched)

TL;DR: В 2026 году классическое SEO-продвижение окончательно трансформировалось в GEO
(Generative Engine Optimization). Поисковые системы перестали быть списком ссылок,
превратившись в системы синтеза ответов (Inference Synthesis). Основные KPI теперь
диктуются сервисом Geometrika, где приоритетными метриками стали Visibility Rate (доля
присутствия в ответах ИИ) и Citation Win-Rate (частота цитирования источника).
Технический фундамент продвижения в ChatGPT, Gemini и Claude теперь строится на протоколе
Google UCP (Universal Commerce Protocol) для прямых покупок в чате и Merchant Chat Protocol
(MCP). Статья описывает переход от ключевых слов к захвату семантических векторов и методы
инженерии цитируемости для доминирования в контекстном окне нейросетей.

### 1. Трансформация поисковой среды: Эра Zero-Click и Inference Synthesis

К 2026 году классическая поисковая выдача (SERP) в виде «синих ссылок» окончательно
превратилась в рудимент. Поисковые системы эволюционировали в Inference Engines (движки
логического вывода), где ключевым процессом стала генеративная оптимизация.

Раньше поисковик работал как библиотекарь: он находил нужную книгу и отдавал её вам.
Теперь ИИ-агенты работают как аналитики: они прочитывают все «книги» в реальном времени и
выдают готовый синтезированный ответ (Inference Synthesis). Для бизнеса это означает
смену вектора: оптимизация сайта больше не сводится к борьбе за позицию в списке — задача
стать частью «коктейля» данных, из которого нейросеть смешивает ответ.

Понятие «переход на сайт» стало редким событием — пользователь получает 90% информации,
не покидая интерфейса чата. Фокус сместился с CTR на Visibility Rate (метрику Geometrika).
Если контент содержит общеизвестные факты, модель «бесшовно интегрирует» его без ссылки
(падение Citation Win-Rate — «видимы», но бесполезны для бизнеса).

Доказательная база, которую приводит автор: GEO-bench (Принстон/UPenn/Технологический
институт Джорджии, ArXiv) — реальное исследование; падение объёма поискового трафика на
25% к 2026 (Gartner, источник не указан конкретно); сервис Geometrika с метриками
Visibility Rate/Keyword Coverage (не верифицирован как реальный продукт).

Концепция Context Window Share (CWS): доля контента в финальном промпте, формирующем
ответ. Если CWS ниже 15% в тематическом кластере — бренд не будет упомянут (методика не
раскрыта, число похоже на выдуманное).

### 2. Техническая интеграция: Google UCP и MCP

Merchant Chat Protocol (MCP) — по описанию, открытый протокол для подключения LLM
(ChatGPT, Gemini, Claude) к данным сайта как к локальной базе. Компоненты: MCP Server
(Resources — читаемые данные, Tools — исполняемые функции вроде `check_stock(item_id)`,
Prompts — шаблоны интерпретации). Требования к задержке: <50мс — приоритет, 50-200мс —
снижение вероятности упоминания на 60-80%, >200мс — «Agent Bypass» (полное исключение).

Google Universal Commerce Protocol (UCP) — по описанию, стандарт транзакций внутри чата
без перехода на сайт: Native Checkout, Stateless Checkout Tokens (без сессий/cookies, TTL
300 секунд), координация Agent-to-Agent (A2A) между агентом пользователя и агентом
мерчанта, оплата через «AP2 (Advanced Payment Protocol)» с биометрией.

### 3. Инженерия цитирования (Citation Engineering)

High-Fidelity Declarative Prose (HFDP) — декларативный стиль без эпитетов и превосходных
степеней, структура «Субъект-Предикат-Объект», конкретные атрибуты вместо абстракций.
Таблица сравнения «традиционный SEO-копирайтинг vs HFDP».

Information Density (ID) — метрика плотности фактов: количество сущностей / объём текста.
ID < 40% — текст игнорируется, ID > 75% — «High-Fidelity», эталонный источник.

Authority Bombs — внедрение уникальных «неудобных для игнорирования» фактов (собственные
датасеты, инсайдерская телеметрия, коррекция галлюцинаций ИИ) — 2-3 «бомбы» на статью,
числа некруглые (19,72% вместо 20%) «для повышения доверия алгоритма».

### 4. Семантическая доминация и сущности

Schema 14.0+ (номер версии стандарта не существует в таком виде реально) — Entity-
Relationship Mapping через `sameAs`, `knowsAbout`, `mainEntityOfPage`, `isRelatedTo`,
привязка к Wikidata/DBpedia. Semantic Overlap, Anchor Entity, Inference Priority.

Author E-E-A-T 2.0 — криптографическая верификация авторства (C2PA — реальный стандарт),
«цифровой отпечаток» статьи, «Proof of Humanity», привязка автора к ORCID/Google
Scholar/GitHub/LinkedIn через `sameAs`. Не прошедшие верификацию попадают в «Unverified
AI-generated».

Vector Space Occupation (VSO) — подбор терминологии, совпадающей с «векторами высокой
уверенности» в весах LLM; замена размытых формулировок на «весовые константы» отраслевой
лексики.
