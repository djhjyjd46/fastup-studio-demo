# Первый полный замер через API Яндекс.Вебмастера

Источник: `scripts/yandex_webmaster_report.py --days 28 --all`, host `fastup.by`,
период 2026-07-12 — 2026-08-08. Полный список — 609 запросов, все собраны (пагинация
по 500 за раз). Это **базовая линия** (baseline) — до этого дня замеров через Яндекс
не было, сравнивать пока не с чем, сравнение станет возможно со следующего замера.

**Оговорка про методологию, важно не путать с GSC:** у Яндекс.Вебмастера в API нет
измерения по конкретной странице — только запросы по всему сайту целиком. Числа
здесь не сопоставлять напрямую с позициями из `scripts/gsc_report.py` (Google считает
позицию иначе, чем `AVG_SHOW_POSITION` у Яндекса).

## Общая картина

- **1399 показов, 43 клика за 28 дней. CTR 3.07%** — заметно ниже, чем у сильных
  страниц в Google (для сравнения, `/o-nas/` в GSC — 9.29%, `kak-vybrat-veb-studiyu` —
  8.82%). Разница ожидаема отчасти по методологии (у Яндекса в выдачу попадает и
  длинный хвост нулевых кликов, которого GSC может не показывать так же полно), но
  сам факт низкого CTR по денежным запросам — сигнал смотреть на сниппеты/тайтлы.
- **36 из 609 запросов дали хотя бы 1 клик** — длинный хвост почти без отдачи, типично
  для молодого домена без раскрученного бренда.

## Главная находка: высокие показы, ноль кликов — сниппет-проблема, не позиция

Несколько денежных запросов уже на хорошей позиции (топ-10), но не получают кликов
вообще — это не «нас не видно», это «нас видно, но не кликают»:

| Запрос | Показы | Позиция | Клики |
|---|---|---|---|
| `продвижение бизнеса под ключ` | 146 | 6.84 | 2 (CTR 1.4%) |
| `какой сайт нужен вашему бизнесу гайд по выбору без воды` | 12 | **3.00** | 0 |
| `услуги разработка и продвижение сайтов` | 9 | 6.11 | 0 |
| `как выбрать веб-студию в беларуси` | 7 | **2.00** | 0 |
| `fastup.by` (брендовый) | 5 | **1.80** | 0 |

Особенно заметно: `как выбрать веб-студию в беларуси` на позиции 2.00 и
`fastup.by` (прямой брендовый запрос) на позиции 1.80 — оба фактически на первом
месте выдачи, и ни одного клика за месяц. Для брендового запроса это может быть
статистическая мелочь (низкий объём), но для позиции 2.00 по денежному запросу —
стоит проверить, как выглядит сниппет в самой яндексовской выдаче (title/description
могли не подхватиться корректно, либо конкурирует description от Rank Math, оптимизированный
под Google, а не под то, что реально показывает Яндекс).

**Практический вывод:** прежде чем писать что-то новое под эти запросы — посмотреть
глазами, как страница выглядит в реальной выдаче Яндекса, и при необходимости
поправить сниппет, а не контент.

## Аномалия: «гаптика» — 3 связанных запроса, ни одной страницы под них

`гаптика` (37 показов, поз. 9.95), `гаптика это` (19, поз. 10.32), `что такое гаптика`
(9, поз. 9.44) — суммарно 65 показов, но **ни один пост/страница/черновик в WordPress
не содержит этого слова** (проверено `wp post list --s="гаптика"` — 0 результатов).
Рядом всплывают ещё несколько запросов той же тематики (`tactile ux`, `эмоциональный
интеллект в дизайне`, `тактильный веб интерфейс`) — тоже без соответствующего контента
на сайте.

Не расследовал глубже (не входило в задачу замера) — вероятная причина: остаток
индексации старой удалённой страницы после чистки контента 2026-08-03
(`geo/2026-08-03-site-content-audit.md`), которую Яндекс ещё не до конца забыл. Не
конвертирует в клики (0 из 65 показов), не денежный интент — **не тратить на это
ресурс специально**, но если через месяц эти запросы не исчезнут сами — можно будет
поискать глубже (кэш Яндекса, старые редиректы).

## Что дальше

1. **Следующий замер — через 2-3 недели**, тем же способом
   (`python3 scripts/yandex_webmaster_report.py --days 28 --all`), сравнить с этим как
   с базовой линией — увидеть, сдвинулись ли денежные запросы после перелинковки
   2026-08-08 (`promotion/internal-linking-map.md`).
2. **Проверить сниппеты вручную** по трём находкам с высокой позицией и нулевым CTR
   (`как выбрать веб-студию в беларуси`, `какой сайт нужен вашему бизнесу`, `fastup.by`) —
   зайти в саму выдачу Яндекса и посмотреть глазами, что реально показывается.
   **Первая уже проверена (2026-08-08, вечером, Егор прислал скриншот выдачи):**
   по `как выбрать веб-студию в беларуси` Яндекс вытягивает в сниппет кусок FAQ-ответа
   про цену («Разброс большой и зависит от сложности. У нас, например, лендинг
   начинается от 1100 белорусских рублей...») — не заголовок и не description
   страницы, а фрагмент текста, который сам счёл релевантнее. Это объясняет нулевой
   CTR при позиции 2.00: сниппет отвечает не на тот вопрос, который человек искал
   («как выбрать»), а на другой («сколько стоит»), с которым сама страница тоже
   работает через FAQ. **Не проверено ещё:** `какой сайт нужен вашему бизнесу`,
   `fastup.by`.

   **Сделано в тот же вечер (без нового текста):** переставлен порядок FAQ —
   вопрос «Как понять, что студия не пропадёт через полгода» теперь идёт первым,
   вопрос про цену сдвинут на третье место. Опубликовано, проверено в живой
   JSON-LD разметке.

   **Наблюдение, важное уточнение от Егора:** расхождение между запросом с «в Беларуси»
   и без — это **не эффект сегодняшней правки FAQ**, оно было так с самого начала,
   до переупорядочивания. Для запроса **без** «в Беларуси» Яндекс уже показывал
   хороший сниппет — прямой ответ-блок из начала статьи («Портфолио в действии,
   а не картинки...»), не FAQ. Для запроса **с** «в Беларуси» показывал (и после
   правки продолжает показывать) FAQ про цену. Значит объяснение «не успело
   переиндексироваться» снимается — расхождение системное, не временное.
   Рабочая гипотеза: сама фраза «в Беларуси» дословно совпадает с текстом вопроса
   про цену («Сколько стоит сайт **в Беларуси** в 2026 году?»), и для запроса,
   содержащего эту же фразу, алгоритм отдаёт приоритет точному текстовому
   совпадению со словами запроса — сильнее, чем позиции блока в списке. Если
   это верно, переставлять порядок дальше бесполезно для гео-варианта запроса —
   нужно менять сам текст вопроса (убрать «в Беларуси» из вопроса про цену или
   явно вписать «в Беларуси» в вопрос, который отвечает на «как выбрать»).
   **Проверить в следующем замере** (через 2-3 недели): если снипет для
   гео-варианта так и не сдвинется — гипотеза подтверждена, чинить текстом.

   **Сделано в ту же ночь:** страница отправлена на переобход через API
   (`--recrawl`, добавлен в `scripts/yandex_webmaster_report.py`,
   `POST /recrawl/queue`) — это не гарантирует мгновенный пересчёт сниппета,
   только поднимает страницу в очереди краулера. Реальный эффект тоже смотреть
   в следующем замере.

   **Расширено на все страницы, изменённые за сессию 2026-08-08 (по просьбе
   Егора — «мы же всё меняли»):** отправлено 14 URL на переобход, все `202 OK`
   (квота ушла со 150 до 135):
   - Главная (`/`), `/razrabotka-saitov/`, `/kontakty/`, `/oplata/` — задела
     перелинковка карусели и/или атрибуция заявок (скрытые поля в формах).
   - Все 10 статей блога — минимум hero-блок с миниатюрой (задел шаблон
     `single-article.php` целиком), 8 из них ещё и новые внутритекстовые ссылки.
   - Не тратить время на разбор «сработало ли именно это» по каждой странице
     отдельно — цель была одна: не ждать планового обхода, ускорить момент,
     когда Яндекс вообще увидит правки. Следующий полный замер (через 2-3 недели)
     покажет совокупный эффект.
3. Аномалию с «гаптикой» — не трогать, только поглядывать в следующих замерах.
