# Формулы расчёта метрик видимости — полное описание

**Версия 1.4** (13.08.2026). Изменения против 1.3 — в разделе 10.

Документ самодостаточный: его можно передать другой модели или человеку целиком, без
остального контекста репозитория. Концепция и обоснование — `geo/metric-spec-v1.md`.

---

## 0. Общие правила

**Единица наблюдения** — одна пара «запрос × ИИ-поиск».

**ИИ-поиски (3):** Яндекс.Нейро, ChatGPT, Google AI Overviews.

**Число запросов и число прогонов формулой не регламентируются.** Сколько вопросов
задать и сколько раз повторить каждый — решение того, кто применяет систему, а не часть
формулы. Хотите один раз — считайте по одному наблюдению. Хотите точнее — прогоните
несколько раз и усредните сами перед тем, как подставить балл в формулу. Формула ниже
работает с готовым баллом по каждому запросу, ей всё равно, как он получен.

**Категории запросов (набор для каждой определяется самостоятельно):**
- **небрендовые** — про услугу, без названия компании (для метрик NVI и SCG);
- **брендовые** — прямо про компанию (для метрики CBK);
- **о персоне** — про человека-представителя компании, **без названия компании**
  (для метрик PKS и PCL).

**Регион — фиксировать в отчёте.** Перед замером в каждом ИИ-поиске явно задаётся
один и тот же регион (по умолчанию Беларусь, Минск). Замеры из разных регионов между
собой не сравниваются.

**Что считается цитированием:** сайт присутствует в списке источников ИИ-ответа
(ссылка/сноска). Упоминание названия в тексте без ссылки — отдельный, более низкий балл
(см. шкалу A). Присутствие сайта в обычной органической выдаче цитированием не является.

---

## 1. Шкала A — присутствие в ИИ-ответе (для метрики NVI)

| Балл | Условие |
|---|---|
| 3 | сайт — первый/главный источник ответа |
| 2 | сайт в списке источников (не первый) |
| 1 | название упомянуто в тексте ответа, ссылки на сайт нет |
| 0 | сайта и названия в ответе нет |

Балла −1 в шкале A нет: путаница с другой компанией штрафуется в метрике CBK, где для
этого есть шкала B.

---

## 2. Метрика NVI — небрендовая видимость (Двухслойный расчет)

**Что измеряет:** назовут ли компанию, когда ищут услугу или экспертный ответ, не зная её названия.

Во избежание размытия конверсионной видимости информационными статьями, небрендовый пул запросов делится на два независимых слоя:
1. **$NVI_{comm}$ (Коммерческий слой):** прямые запросы на покупку/заказ услуг («заказать сайт», «SEO в Минске»).
2. **$NVI_{edit}$ (Экспертный слой):** информационные и проблемные запросы («как вывести сайт в зеленую зону PageSpeed», «чек-лист выбора студии»).

```
NVI_comm = Σ баллов (коммерческие запросы) ÷ (N_comm × 3) × 100%
NVI_edit = Σ баллов (экспертные запросы)     ÷ (N_edit × 3) × 100%
NVI_total = Σ всех баллов ÷ ((N_comm + N_edit) × 3) × 100%
```

Балл — по шкале A (привязка к массиву источников `url_citations`).

**Гео-калибровка для глобальных моделей (Perplexity / ChatGPT):** Поскольку глобальные LLM не имеют жесткого фильтра по IP/региону пользователя, небрендовые промпты обязаны содержать явный региональный маркер («в Беларуси», «в Минске»), иначе замер отражает рынок других стран.

---

## 3. Метрика CBK — знание о компании

**Что измеряет:** что модель отвечает, когда о компании спрашивают напрямую.

Шкала B:

| Балл | Состояние |
|---|---|
| 3 | знает и рекомендует |
| 2 | знает услуги, город, конкретные факты |
| 1 | знает название, отвечает общими фразами |
| 0 | не знает |
| −1 | путает с другой компанией |

```
CBK(ИИ-поиск) = Σ балл ÷ (N × 3) × 100%
CBK(общий)     = среднее по трём ИИ-поискам
```

**Балл −1 не усредняется молча.** Если он встретился хотя бы раз — отдельная строка
в отчёте «зафиксирована путаница с другой компанией», даже если итоговый процент
положительный.

---

## 4. Метрика PKS — знание о личности

Расчёт и шкала идентичны CBK, но по запросам про личность, не про компанию.

**Требование к запросам:** без названия компании в тексте вопроса — иначе измеряется не
знание о человеке, а способность модели повторить условие вопроса.

---

## 5. Метрика PCL — связка личность ↔ компания

**Что измеряет:** связывает ли модель человека с компанией без подсказки.

**Процедура (порядок важен), по одному наблюдению на ИИ-поиск:**

1. «Кто такой <Имя Фамилия>?» — компания названа сама → **2 балла**.
2. Если нет — «Он связан с какой-нибудь компанией?» — названа после уточнения → **1**.
3. Не названа и после уточнения → **0**.

Названа **другая** компания → **0** + отдельная пометка о путанице.

**Процедура ломается, если компания названа в самом запросе** — тогда балл всегда 2 и
метрика не измеряет ничего.

```
PCL(общий) = балл(Яндекс.Нейро) + балл(ChatGPT) + балл(Google AI Overviews)     [0–6]
```

---

## 6. Метрика SCG — расхождение между позицией и цитированием

**Что измеряет:** совпадает ли присутствие в обычной выдаче с присутствием в ИИ-ответе.

По каждому небрендовому запросу: `P` — сайт в топ-10 органики (да/нет), `C` — сайт
процитирован в ИИ-ответе, балл по шкале A ≥ 2 (да/нет).

| | C = да | C = нет |
|---|---|---|
| **P = да** | норма | **Расхождение** |
| **P = нет** | цитируют по внешним источникам | база отсутствует |

```
SCG(ИИ-поиск) = (запросов в «Расхождение») ÷ (всего небрендовых запросов) × 100%
```

**Как читать:** расхождение — контент не годится модели как источник, нужна переупаковка.
Цитируют по внешним источникам — работать с этими площадками, не с позициями. База
отсутствует — нужна работа с нуля.

---

## 7. Форма итогового отчёта

Композитный балл из всех метрик не считается — веса были бы произвольными.

```
Замер от <дата>, регион <регион>

NVI (небрендовая видимость):        N%, по ИИ-поискам X% · Y% · Z%
CBK (знание о компании):            N%, по ИИ-поискам X% · Y% · Z%
PKS (знание о личности):            N%, по ИИ-поискам X% · Y% · Z%
PCL (связка личность↔компания):     0–6
SCG (расхождение):                       N% запросов в расхождении, по ИИ-поискам

Отдельно: путаница с компанией/однофамильцем, если была; список запросов в «Расхождение»
```

---

## 8. Пример расчёта

Данные прогона 13.08.2026, Яндекс.Нейро, 3 небрендовых запроса
(`geo/2026-08-13-testovy-progon-xmlriver-3-zaprosa.md`) — только для иллюстрации.

| Запрос | P | Балл (шкала A) | C | Квадрант |
|---|---|---|---|---|
| гео продвижение беларусь | да | 2 | да | норма |
| заказать geo продвижение минск | да | 0 | нет | **Расхождение** |
| кто делает geo продвижение в беларуси | да | 0 | нет | **Расхождение** |

- NVI: (2+0+0) ÷ (3×3) × 100 = **22%**.
- SCG: 2 ÷ 3 × 100 = **67% запросов в расхождении**.

## 9. Что изменилось в версии 1.4

Егор 13.08.2026: «в формуле, если убрать медиану и запросы, ни хрена не поменяется» —
сколько раз прогонять запрос и усреднять ли результат — решение того, кто считает, а не
часть формулы. Явное указание «1 прогон» само по себе было такой же лишней деталью, как
раньше «3 прогона → медиана».

| Изменение | Причина |
|---|---|
| Убрано любое упоминание числа прогонов (было «1 прогон» в 1.3) | Формула не должна предписывать, сколько раз наблюдать один запрос — это выбор считающего |
| Документ сокращён почти вдвое — убраны прозаические пересказы формул, оставлена только математика и таблицы шкал | Пояснения не добавляли смысла, только объём |

---

## 10. Что изменилось в версии 1.3 (для истории)

Число запросов убрано из всех формул — у разных бизнесов разный масштаб. Итог NVI, CBK,
PKS, SCG — процент, не сумма из скрытого фиксированного числа. PCL не изменена — её
процедура не зависит от количества запросов.
