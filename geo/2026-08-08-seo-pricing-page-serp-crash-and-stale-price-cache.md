# `/seo-pricing-mesyats-belarus/` — обвал позиции на 2 страницу + устаревшая цена в кэше Яндекса

Источник: Егор вручную проверил живую выдачу по запросу «сколько стоит seo продвижение
сайта в месяц беларусь» (или близкому — см. уточнение ниже) и прислал текст сниппетов.

## Находка 1 — обвал позиции в обеих системах

- **Яндекс:** была топ-1 (зафиксировано ранее в базе), сейчас — **вторая страница
  выдачи, вторая позиция на ней**.
- **Google:** тоже вторая страница, третья позиция после рекламных блоков.

Совпадает по направлению с GSC-замером от 2026-08-05 (позиция 23.85 → 30.16,
`geo/2026-08-05-gsc-mesyats-otchet.md`), но по факту ещё хуже — судя по описанию Егора
("очень сильно так упала"), сейчас это уже конец 2-й/начало 3-й десятки или ниже.
**Точную позицию замерить следующим прогоном** `scripts/yandex_webmaster_report.py`
и `scripts/gsc_report.py` — пока это качественная оценка Егора "на глаз" по номеру
страницы выдачи, не число.

Причина обвала не установлена. Кандидаты на проверку:
- то же системное вытеснение из авто-ротации/перелинковки, что уже находили для этой
  страницы 2026-08-08 (см. TODO.md п.12, `promotion/internal-linking-map.md`);
- сама смена цены 600→800 BYN в статье 2026-08-08 могла временно просадить релевантность,
  пока не переиндексируется целиком;
- конкуренты подвинулись — не проверялось.

## Находка 2 — сниппет Яндекса показывает устаревшую цену

Живой текст в выдаче Яндекса: *«первый месяц у нас стоит дороже, от 1000 BYN, дальше
дешевле, около **600 BYN**»* — это старая цена, до синхронизации 600→800 BYN,
проведённой в тот же день 2026-08-08 (TODO.md, "Цена SEO-ведения синхронизирована
600→800 BYN"). Живая страница уже показывает 800 BYN, кэш Яндекса — нет.

Это НЕ проблема качества/конверсионности текста description — это обычное
рассинхронизация с кэшем поисковика. `--recrawl` по этому URL уже отправлен
2026-08-08 вечером (см. `2026-08-08-yandex-webmaster-pervy-zamer.md`, список из 14 URL).
Должно самоисправиться при следующем обходе.

## Вывод — не трогать description

Рекомендация наставника (см. диалог 2026-08-08): **не переписывать description сейчас**.
Причины:
1. Нулевая конверсия объясняется позицией на 2-й странице выдачи, а не формулировкой
   текста — на такой позиции CTR низкий независимо от качества сниппета.
2. Показанная сейчас цена 600 BYN всё равно устареет при следующем обходе Яндекса —
   переписывать текст под неё сейчас бессмысленно вдвойне.

## Что дальше

1. Следующий полный замер (Яндекс.Вебмастер + GSC, через 2-3 недели по уже
   запланированному циклу) — получить точную позицию, не «на глаз».
2. Разобраться, почему позиция обвалилась именно сейчас (что менялось на странице/сайте
   в этот период) — приоритетнее, чем description.
3. Description трогать только после того, как позиция вернётся в зону видимости
   (топ-10-15) и снипет в реальной выдаче перестанет быть устаревшим кэшем.
