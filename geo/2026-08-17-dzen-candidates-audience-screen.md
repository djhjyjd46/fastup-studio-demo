# Проверка аудитории 4 оставшихся Дзен-кандидатов (screening по новому правилу метода)

Начало внешнего контент-плана (внутренний план для fastup.by закрыт, внешнее продвижение
только начинается). Источник кандидатов — `geo/2026-08-17-chankovanie-dzen-stoimost-sayta.md`,
раздел «Шаг 0», темы №3-№6 (№1 и №2 уже использованы/заняты).

Метод — новое правило `geo/METHOD-chankovanie.md` («Проверка целевой аудитории интента»):
для каждого кандидата открыт живой конкурент на dzen.ru через браузер (WebFetch/скрипт
упираются в форму входа Яндекс.Паспорта — рабочий обход только через Browser-инструмент)
и оценена аудитория конкурента до решения писать/не писать.
