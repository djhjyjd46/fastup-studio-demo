# Разбор чужого GEO-скилла (geo-seo-claude) — что забрали, что отбросили

Источник: `github.com/zubair-trabzada/geo-seo-claude` — сторонний скилл-пак для Claude Code
(`/geo audit`, citability-скоринг, проверка краулеров, схемы, PDF-отчёты).

**Решение: не устанавливать.** Причины:
1. Ставится через `curl … install.sh | bash` — выполнение кода незнакомого автора на машине,
   где лежат SSH-ключи от хостинга и VPS. Неприемлемо.
2. Дублирует уже подключённые скиллы `aeo-geo` и `fastup-content` — два набора с одинаковыми
   командами дадут расходящиеся источники правды.
3. Автор сам пишет в `docs/scoring-methodology.md`, что веса «отражают суждение авторов» и
   не выведены из контролируемого исследования. Значит, это чек-лист, а не метрика.

Забрали только идеи. Ниже — то, что реально пригодно, и отдельно то, чему верить нельзя.

## Годное: структура текста под цитирование ИИ

Согласуется с тем, что мы уже делаем в `content/PIPELINE.md` и `fastup-content`, но даёт
более конкретные ориентиры по форме абзаца:

- Блок под извлечение — **самодостаточный кусок 130–170 слов** между заголовками. Смысл
  требования понятен и без чужих цифр: ИИ вырезает кусок из середины страницы, и он должен
  читаться без остального текста.
- **Прямой ответ в первых 1–2 предложениях после заголовка**, разворачивание — дальше.
  Не «давайте разберёмся», не заход издалека.
- Конструкция определения в начале: «X — это …». Тема названа явно, а не местоимением.
- **Мало местоимений** («это», «он», «они») — каждый блок сам называет свой предмет.
- Заголовки — вопросами, как их формулирует человек в поиске.
- Сравнение трёх и более пунктов — **таблицей**, процесс — нумерованным списком.
- Цифра вместо оценки: «800 BYN/мес», «за 3 недели» вместо «недорого», «быстро».
- Ссылка на источник с датой вместо «исследования показывают».
- Чистая иерархия H1→H2→H3 без пропусков уровней.

Практический вывод для нас: это ровно то, чем можно дополнить самопроверку `content-writer` —
не как «скоринг», а как форма абзаца.

## Годное: технические проверки

- Список ИИ-краулеров для проверки robots.txt: **GPTBot, OAI-SearchBot, ChatGPT-User,
  ClaudeBot, PerplexityBot** (критичные) + Google-Extended, GoogleOther, Applebot-Extended,
  Amazonbot, FacebookBot. Проверять не только robots.txt, но и мета-robots, заголовок
  `X-Robots-Tag`, наличие `llms.txt`.
- **JSON-LD, вставленный джаваскриптом, ИИ-краулеры не видят** — разметка должна отдаваться
  сервером. Для нас актуально: проверить, что схемы на fastup.by именно в HTML ответа.
- Клиентский SPA с пустым `<body>` до выполнения JS для ИИ невидим (нас не касается, WP).
- `sameAs` на 3+ площадки в Organization-схеме — единственная часть их схема-скоринга,
  которая совпадает с реальной рекомендацией Google по entity-связности.

## Годное: платформенные различия (как гипотезы, не как факт)

- **Google AI Overviews** — тянет из того, что уже в топ-10 обычной выдачи. То есть GEO там
  не отдельный канал, а надстройка над SEO. Для нас это подтверждает приоритет: сначала
  позиции, потом «оптимизация под ИИ».
- **ChatGPT** ходит в индекс Bing → есть смысл завести Bing Webmaster Tools (у нас сейчас
  только GSC и Яндекс.Вебмастер — см. `2026-08-08-full-baseline-gsc-webmaster-metrika.md`).
- **Perplexity** тянет обсуждения (Reddit и подобное) и свежесть с видимыми датами.
- **Gemini** завязан на экосистему Google: Knowledge Panel, Google Business Profile, YouTube.

## Чему верить нельзя

- **Веса формулы GEO-score** (Citability 25% / Brand 20% / E-E-A-T 20% / Technical 15% /
  Schema 10% / Platform 10%) — авторская выдумка, признанная автором. В отчёт клиенту такую
  цифру ставить нельзя: это выглядит как измерение, а является мнением.
- **Точные пороги** («134–167 слов», «40–60 слов на ответ», «буст цитирования 2.1x»,
  «+40% за статистику») — источник не приводится или приводится частично. Направление верное,
  конкретные числа — не использовать как факт, ни в тексте наружу, ни в разговоре с клиентом.
- **Корреляции из ссылки на «исследование Ahrefs, декабрь 2025»** (YouTube 0.737, домен 0.266)
  — не проверены нами по первоисточнику. Если понадобится — сверять отдельно.
- **llms.txt** — сам автор пишет, что стандарт не принят ИИ-краулерами повсеместно. Делать
  можно (дёшево), продавать как фактор — нет.
- **Баллы за security-заголовки** (HSTS, CSP, X-Frame-Options) в GEO-скоринге — притянуто:
  это гигиена безопасности, связь с цитируемостью в ИИ не показана.

## Что из этого стоит сделать у нас

1. Проверить fastup.by по списку ИИ-краулеров (robots.txt + `X-Robots-Tag` + мета-robots).
2. Проверить, что JSON-LD отдаётся в HTML сервером, а не вставляется скриптом.
3. Завести Bing Webmaster Tools — дешёвый шаг, влияет на ChatGPT.
4. Дополнить самопроверку `content-writer` требованиями к форме абзаца из раздела выше.
