# GEO-пайплайн простыми словами (без жаргона) — версия для объяснения не-технарю

Это разговорная версия `geo/GEO-AUDIT-PIPELINE.md` — та же методика, без метрик и формул,
которой Егор пользуется, когда объясняет суть человеку без технического бэкграунда
(зафиксировано на примере объяснения маркетологу Ире, 2026-08-18). Соответствие этапов —
в конце файла.

## Схема (как объясняет Егор)

1. **Собираем информацию о сайте.** Проводим техническую проверку, при необходимости —
   доработку.
2. **Собираем информацию о нахождении бренда.** Где он вообще есть, в каких источниках
   упоминается.
3. **Создаём паспорт.** Формируем данные о компании, размещаем их на площадках, связываем
   между собой (чтобы разные источники не противоречили друг другу).
4. **Строим карту интентов.** Собираем поисковые запросы (обычный Вордстат), разбиваем их
   на части, декомпозируем интент — так, как это будет делать нейросеть, а не просто по
   ключевым словам. Из этого собирается большая карта интентов.
5. **Закрываем карту интентов внутренними страницами.** Работаем с внутренними страницами
   сайта на основе этой карты — каждая часть карты должна быть закрыта конкретным контентом.
6. **Последний этап — внешнее подтверждение экспертности.** Самый дорогой и сложный этап:
   размещение экспертных статей на крупных внешних площадках (VC.ru, Хабр и т.п.), которые
   со временем подтверждают авторитет бренда. Егор пока не определился, как этот этап
   упаковать/оформить в отдельную услугу.

## Соответствие технической версии (`geo/GEO-AUDIT-PIPELINE.md`)

| Пункт разговорной версии | Соответствует |
|---|---|
| 1–3 (техпроверка, поиск бренда, паспорт) | Фаза 1 (техаудит) + Спринт 1 (Entity Foundation: Schema.org, `sameAs`, NAP) |
| 4 (карта интентов, декомпозиция) | Фаза 2 (Intent Mapping) |
| 5 (закрытие картой внутренних страниц) | Спринт 2 ($NVI_{edit}$-бустер, сателлиты) |
| 6 (внешнее подтверждение, дорого) | Спринт 3 (Off-page E-E-A-T: Хабр/VC) — открытый вопрос упаковки в отдельный продукт |

Расхождений по сути нет — это тот же пайплайн, просто без формул/метрик, для устной подачи.
