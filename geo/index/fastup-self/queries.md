Набор взят один в один из `../../query-set-2026-07.md` — это единственный набор, по
которому существует **валидная точка «до»**: ручной замер 12.08.2026 через реальные
интерфейсы (`../../2026-08-12-polny-zamer-citiruemosti.md`), где FastUp был процитирован
2 раза из ~104 проверок.

Почему не 44 интента из baseline 14.08: тот замер снимал органическую выдачу вместо
ИИ-ответов и сравнивать с ним нечего
(`../../2026-08-22-oshibka-zamera-gas-merili-vydachu-a-ne-ii-otvet.md`).

**Оговорка для методики, обязательная:** точка «до» снята вручную через интерфейсы
браузера, точка «после» — через API. Поверхности близкие, но не идентичные; при
публикации это указывается прямо.
