## 4. Выводы

1. **Рост сайта за две недели держится на рекламе, не на органике.** +35 визитов к
   28-дневному окну при +69 рекламных — то есть органические каналы в сумме минусуют.
   В 14-дневном окне реклама — крупнейший источник (71 из 195 визитов, 36%).
2. **Поиск падает по всем трём источникам одновременно.** Метрика: 108 → 76 визитов
   (−30%), по движкам 84 → 69. GSC: клики 32 → 28. Вебмастер: запросов 877 → 559.
   Три независимых замера дают одно направление — это не шум атрибуции.
3. **Показы растут, клики не следуют.** `/razrabotka-saitov/` +40% показов при падении
   кликов вдвое, CTR по сайту 1.32% → 1.10%. Страницы стоят на позициях 45–70, где показ
   ничего не стоит. Работа над охватом без работы над позицией упёрлась в потолок.
4. **Глубина просмотра падает третий замер подряд:** 2.73 → 2.11 → 1.76 страниц за визит.
   Визитов больше, читают меньше — и реклама этот показатель разбавляет дополнительно
   (27с на визит против 72с у прямых заходов).
5. **Вопрос UTM-разметки собственных публикаций открыт с 08.09 и не сдвинулся.** 39%
   трафика (141 визит) неатрибутируемы. Пока это так, вопрос «что сработало» на этих
   данных не решается.
6. **Рекламные визиты — 27 секунд и 1.1 страницы.** Отдельного разбора качества
   рекламного трафика этот замер не даёт, но цифра требует проверки по кампании.
7. **Заявок за месяц — 3 при конверсии 1%.** Трафик вырос, заявки на этом уровне не
   различимы от нуля. Любой вывод «канал X работает лучше» на трёх заявках недопустим —
   нужен объём, а не перекладывание долей.
