# Архив разовых скриптов (scripts/archive/)

Здесь хранятся одноразовые скрипты прошлых миграций, разовых сшивок и исторических замеров.
Они вынесены из корня scripts/, чтобы не захламлять основной каталог боевых инструментов.

Перед запуском любого скрипта отсюда — убедитесь, что он всё ещё актуален, так как инфраструктура
(переезд на hb.by, отключение VPS) могла измениться.
