# Словарь работ: как называется то, что мы делаем

Зачем файл. Работа выполняется, а термина для неё в голове нет — и на собеседовании,
на созвоне с клиентом и в тексте это читается как «нахватался по верхам», хотя по факту
сделано больше, чем у человека, который знает слова, но не умеет.

Вторая задача файла — обратная: **не присваивать чужие термины.** Заявить своим то, о чём
написаны десятки статей, дороже, чем не знать слова: собеседник перестаёт верить всему
остальному. Поэтому у каждого термина стоит статус.

**Статусы:**
- 🌍 **общепринятый** — устоявшийся термин, есть в документации и литературе. Своим не называть.
- 💬 **отраслевой** — в ходу у практиков, единого определения нет. Использовать можно, ссылаться
  на «стандарт» нельзя.
- 🏷 **наш** — своё название, потому что общепринятого нет. Вводить с оговоркой «мы это называем».

## 1. Спрос и интенты

| Термин | Англ. | Статус | Что это на деле |
|---|---|:---:|---|
| Поисковый интент | search intent | 🌍 | Что человек на самом деле хочет, а не какие слова напечатал |
| Типы интента | informational / navigational / commercial / transactional | 🌍 | Классическая четвёрка. Наши коммерческие страницы работают с двумя последними |
| Карта интентов | intent map / intent mapping | 🌍 | **Приём известный, своим не называть.** Наше — только реализация: веса по важности для сделки плюс векторная проверка закрытости |
| Кластеризация запросов | query clustering | 🌍 | Группировка запросов по смыслу, а не по вхождению слова |
| Декомпозиция запроса | query decomposition / multi-hop | 🌍 | Как LLM разбивает длинный вопрос на 3–5 коротких подзапросов. Механика, из-за которой блок должен быть самодостаточным |
| Расширение запроса | query fan-out | 💬 | То же со стороны движка: один вопрос пользователя превращается в веер поисков |
| Структура спроса | demand distribution | 🌍 | Доли кластеров. Переносится между рынками; объёмы — нет (см. `geo-method.md`) |
| Каннибализация | keyword cannibalization | 🌍 | Две свои страницы конкурируют за один интент, обе проседают |
| Один интент — один URL | canonical intent owner | 💬 | Правило против каннибализации: у интента ровно один хозяин |

## 2. Сущность и знание о компании

| Термин | Англ. | Статус | Что это на деле |
|---|---|:---:|---|
| Сущность | entity | 🌍 | Компания/человек/продукт как объект в графе знаний, а не как строка текста |
| Entity SEO | entity-based SEO | 🌍 | Работа не над словами, а над тем, чтобы система поняла, кто вы |
| Граф знаний | knowledge graph | 🌍 | Связи между сущностями. Wikidata — публичный, у поисковиков свои |
| **Разрешение неоднозначности** | **entity disambiguation** | 🌍 | **Твой случай с индийским тёзкой.** Система не может решить, о ком речь. Лечится жёсткими признаками: УНП, город, `sameAs` |
| Сшивание профилей | entity reconciliation | 🌍 | Соединение разрозненных упоминаний в одну сущность через `sameAs` |
| Согласованность NAP | NAP consistency | 🌍 | Name / Address / Phone одинаковы везде. Расхождение = система не уверена, что это одна компания |
| Значимость сущности | entity salience | 🌍 | Насколько сущность центральна для текста, а не просто упомянута |
| Совстречаемость | co-occurrence | 🌍 | Компания и тема регулярно встречаются рядом. Так формируется «в чём вы эксперт» |
| Цифровой след | digital footprint | 💬 | Совокупность следов персоны/бренда во внешних источниках |
| Паспорт сущности | — | 🏷 | Наше. Сверка «что заявлено в разметке и карточках» против «что отвечают нейросети» |

## 3. Извлекаемость текста (почему из страницы берут фрагмент)

| Термин | Англ. | Статус | Что это на деле |
|---|---|:---:|---|
| RAG | retrieval-augmented generation | 🌍 | Модель сначала ищет фрагменты, потом пишет ответ по ним |
| Чанкинг | chunking | 🌍 | Нарезка текста на фрагменты. Наш профиль: 70 слов, перекрытие 15 |
| Перекрытие | overlap | 🌍 | Фрагменты идут внахлёст, чтобы мысль не рвалась по границе |
| Поиск по пассажам | passage retrieval / passage ranking | 🌍 | Ранжируется фрагмент, а не страница. Причина, по которой длинная страница может проиграть короткой |
| Самодостаточность фрагмента | context independence | 🌍 | Абзац понятен без остальной страницы: с цифрами и названиями внутри себя |
| Ответ первым | answer-first / BLUF / перевёрнутая пирамида | 🌍 | Сначала ответ, потом объяснение. Из журналистики, работает и для извлечения |
| Цитируемость | citability | 💬 | Насколько фрагмент удобно вставить в ответ. Меры нет, оценка качественная |
| Атомарность | atomic content | 💬 | Один блок — один законченный факт |
| Структурированные данные | structured data / JSON-LD | 🌍 | Schema.org: `Organization`, `Service`, `FAQPage`, `Article` |
| Гео-каллаут | geo-callout | 🏷 | Наше название вводного блока H2 на 35–45 слов. Термин внутренний, наружу — «блок прямого ответа» |

## 4. Замеры

| Термин | Англ. | Статус | Что это на деле |
|---|---|:---:|---|
| Эмбеддинг | embedding | 🌍 | Текст как вектор чисел |
| Косинусная близость | cosine similarity | 🌍 | Насколько два текста близки по смыслу. **Порядковая шкала** |
| Порядковая шкала | ordinal scale | 🌍 | Из типологии Стивенса: можно сравнивать, нельзя делить и умножать. Наш косинус — она |
| Базовая линия | baseline | 🌍 | Замер «до». Без него результат недоказуем, кейса не будет |
| Контрольная группа | control group | 🌍 | Страницы, которые не трогали. **У нас её нет** — известная дыра: рост может быть общим трендом |
| Эталон истины | ground truth | 🌍 | Настоящий ответ, с которым сверяют метрику. Для цитирования в ИИ его ни у кого нет |
| Прокси-метрика | proxy metric | 🌍 | Косвенная замена того, что мерить дорого. Косинус — прокси, и его место внутри |
| Прямое наблюдение | direct measurement | 🌍 | Спросили ChatGPT, записали ответ. NVI/CBK/PKS — это оно, множители не нужны |
| **Доля голоса** | **share of voice** | 🌍 | **Классическая маркетинговая метрика, ближайшая родня нашего NVI.** Полезно называть так клиенту: слово знакомое |
| Самосогласованность | self-consistency | 🌍 | Несколько прогонов и медиана — стандартный приём против разброса ответов LLM. Наши три прогона это оно |
| Недетерминированность | non-determinism | 🌍 | Один и тот же запрос даёт разные ответы. Причина, по которой один прогон ничего не значит |
| Галлюцинация | hallucination | 🌍 | Уверенно сказанная неправда. Наш CBK мерит в том числе её |
| Разрыв цитирования | search-citation gap (SCG) | 🏷 | Наше. В топе обычного поиска есть, в ответе нейросети нет |
| Покрытие интентов | intent coverage | 🏷 | Наше название для косинусного замера. **Не** «видимость в ИИ» |

## 6. Процесс и коммерция

| Термин | Англ. | Статус | Что это на деле |

| Результат работы | deliverable | 🌍 | Что клиент физически получает. Продаётся список результатов, не «анализ» |

| Расползание объёма | scope creep | 🌍 | Задача тихо растёт без роста цены. **Наша типовая утечка маржи** |

## Три правила пользования словарём

1. **Есть общепринятый термин — берём его.** Собеседник экономит усилие, а мы получаем доверие
   бесплатно. Своё название поверх чужого термина выглядит как незнание.
2. **Своё вводим с оговоркой.** «Мы называем это разрывом цитирования» — нормально.
   «Существует метрика SCG» — заявка на стандарт, которую попросят подтвердить.
3. **Клиенту — знакомое слово, коллеге — точное.** «Доля голоса в ответах нейросетей» понятнее
   любому маркетологу, чем NVI. Формулу показываем следом, если спросят.

Пополнять по ходу: встретил операцию без названия — ищем устоявшийся термин, и только если его
нет, заводим свой со статусом 🏷.
